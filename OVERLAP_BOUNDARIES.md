# Skill Responsibility Boundaries

These pairs are intentionally separate. Select both only when both distinct deliverables are needed.

| Pair | Boundary |
|---|---|
| `code-review-engineer` / `secure-code-reviewer` | General correctness and maintainability vs security-focused review. |
| `3d-rendering-engineer` / `graphics-engineer` | 3D scene rendering pipeline vs general GPU/2D/visualization programming. |
| `audio-engineer` / `audio-designer` | Signal processing and format quality vs creative documentary soundscape/cue design. |
| `ai-voice-engineer` / `ai-voice-generation-engineer` | Interactive real-time speech systems vs batch narration/TTS generation. |
| `android-voice-engineer` / `ai-voice-engineer` | Android platform integration/permissions/lifecycle vs cross-platform voice AI architecture. |
| `video-processing-engineer` / `automated-video-renderer` | File/stream transformation vs assembling an approved edit timeline into final output. |
| `ai-video-engineer` / `documentary-media-generator` | General AI video product architecture vs executing approved documentary shot generation. |
| `database-engineer` / `database-internals-engineer` | Application schema/query operations vs storage engine and query engine internals. |
| `frontend-engineer` / `ui-ux-engineer` | Production UI implementation vs UX flows, visual system, and design specification. |
| `skill-orchestrator` / `production-orchestrator` | General cross-domain skill selection vs documentary-specific stage gates and artifact control. |
| `documentary-editor` / `automated-video-renderer` | Editorial decisions and timeline plan vs technical render execution and output verification. |
| `voiceover-director` / `ai-voice-generation-engineer` | Narration performance, segmentation, and review direction vs the actual TTS/voice generation integration. |

Do not load both skills just because their names are similar. Use the responsibility boundary above.
