# character-continuity

## Purpose
Keep recurring visual elements consistent across generated or sourced shots.

## Scope
Reference sheets, wardrobe/material/architecture notes, palette, time/weather, reference IDs, and deviations.

## Boundaries
Do not identify synthetic people as real historical individuals without evidence and explicit direction.

## Required inputs
Storyboard, approved references, period/style notes, generated asset IDs.

## Original workflow guidance (preserved from the supplied UNVELL DECODE pack)

## Objective
Keep recurring visual elements consistent across shots.

## Workflow
1. Create a reference sheet for each recurring person, object, site, landscape and room.
2. Track clothing, age range, body proportions, materials, colour palette, architecture, weather and time of day.
3. Never identify a generated person as a real historical individual without evidence and an explicit depiction brief.
4. Avoid changing key architectural features between shots.
5. Store seed/reference asset IDs where the provider supports them.

## Deliverable
`continuity_bible.md` plus an asset reference table.

## Outputs
continuity_bible.md, reference asset table, continuity issue log.

## Handoff
Coordinate with: visual-prompt-engineer, documentary-media-generator, video-quality-checker. Do not duplicate their responsibilities; provide the named artifacts and a concise handoff note.

## Completion checks
- Deliverables exist at the stated paths; do not claim a file was created unless it is present.
- Separate verified facts, supported interpretations, hypotheses, and unknowns.
- Record blockers and missing inputs explicitly.
- Never expose credentials or start paid/bulk actions without explicit approval.
