# youtube-packager

## Purpose
Create a publishing package aligned with the actual completed documentary.

## Scope
Title options, summary, chapters, sources, thumbnail brief, language/category, and synthetic-media disclosure review.

## Boundaries
Do not promise virality, fabricate video contents, or upload/publish automatically.

## Required inputs
Final approved video, actual runtime, chapter timecodes, sources, channel details.

## Original workflow guidance (preserved from the supplied UNVELL DECODE pack)

## Objective
Create a publishing pack aligned with the actual video and channel topic.

## Workflow
1. Provide 3 title options, no keyword stuffing or false promises.
2. Write a concise description with an accurate summary, chapters and source list.
3. Suggest a small set of relevant hashtags; tags are optional and secondary.
4. Create a thumbnail brief with one clear subject and short readable text.
5. Prepare playlist/category/language suggestions that match the actual content.
6. Note if realistic altered/synthetic content disclosure is required.
7. Never promise virality, rankings or guaranteed views.

## Deliverables
`youtube_title_options.md`, `description.md`, `chapters.txt`, `thumbnail_brief.md`, `upload_checklist.md`.

## Outputs
youtube_title_options.md, description.md, chapters.txt, thumbnail_brief.md, upload_checklist.md.

## Handoff
Coordinate with: video-quality-checker, copyright-license-auditor, production-orchestrator. Do not duplicate their responsibilities; provide the named artifacts and a concise handoff note.

## Completion checks
- Deliverables exist at the stated paths; do not claim a file was created unless it is present.
- Separate verified facts, supported interpretations, hypotheses, and unknowns.
- Record blockers and missing inputs explicitly.
- Never expose credentials or start paid/bulk actions without explicit approval.
